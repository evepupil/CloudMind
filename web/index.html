PERSONAL AI MEMORY LAYER

让 AI 记住，但记忆永远属于你。

CloudMind 是部署在你自己的 Cloudflare 账号中的个人 AI 记忆层。它保留原始资料，提炼可追溯的知识，并让不同的 AI 客户端按你的规则调用。

BUILT FOR MEMORY THAT LASTS

长期记忆需要数据主权，也需要可验证的依据。

CloudMind 让每一次召回能够回到来源、时间与版本，避免重要知识只留在不可解释的模型上下文里。

01

先留下真相

URL、文本、PDF 与 MCP 输入先保存为不可变原始快照；摘要、索引和图谱都可以重建。

02

再形成可用记忆

全文、向量和知识图谱协同检索；结论保留来源、版本与有效时间。

03

最后由你授权

个人记忆与 Agent 记忆分域，项目上下文隔离。你决定谁能读取、更新、遗忘或导出。

不可绕过的边界

原始资料、结构化记忆、索引和导出都在你的 Cloudflare 账户中。CloudMind 可以删除、恢复、校验和迁移，但从不把所有权带走。
