## 已落地基础

- 日期范围过滤和 recency 排序归 M1 检索能力。
- 显著性衰减、访问回写和关系图召回归 M2 知识图谱能力。
- 三维组合过滤和项目隔离归 M3 Agent 记忆面。

## 归档设想

```text
relative event query -> resolve anchor -> absolute date filter
rating query         -> candidate set -> dimension scoring
aggregate query      -> candidate set -> count / trend / summary
manual feedback      -> target validation -> salience / explicit edge
```

曾考虑的能力包括：

- 相对事件锚定，例如“上次发布后”。
- 评价维度和超级值排序。
- 跨记忆计数、趋势和阶段总结。
- 手动强化和显式建立关系。

这些能力没有进入当前产品路线。现有 Agent 可以通过多步召回处理一部分需求；
其余能力需要先有真实使用证据，再决定数据模型和 MCP 契约。
