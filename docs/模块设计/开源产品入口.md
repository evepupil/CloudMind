# 开源产品入口

> 模块定位：面向开源用户说明 CloudMind 的产品价值、架构边界和自托管入口的独立静态网站。
>
> 对应代码：`web/index.html`、`web/styles.css`、`web/main.js`、`web/public/observatory-overview.png`
>
> 所属 M 里程碑：[`M8 开源产品入口`](../roadmap.md#m8-开源产品入口)
>
> 当前状态：已完成
>
> 最近更新时间：2026-07-27

## 职责与边界

- 在首屏说明个人 AI 记忆层、BYOC 和数据主权，导向仓库内的部署说明。
- 用真实 Observatory 设计稿展示产品工作台，避免用抽象 AI 插画代替可检查的产品能力。
- 独立于 HonoX 管理工作台：页面不读取用户数据，不包含登录、token 或 Cloudflare 绑定。
- 面向静态托管，可由 Cloudflare Pages 或任意静态文件服务直接发布。

## 结构与数据流

```text
访客 -> web/index.html -> GitHub README / 部署说明
                  -> Observatory 截图（产品能力示意）
```

页面中的个人 / Agent 记忆切换只切换展示文案，不发起网络请求、不持久化任何状态。

## 关键决策

1. 使用原生 HTML、CSS 和 JavaScript，不引入第二套构建链，便于独立静态托管。
2. 采用桌面双栏首屏：产品工作台截图和价值主张同时可见，手机端再收为单列。
3. 复用 Observatory 的深墨、骨白、黄铜和低饱和绿色，而保留产品入口独立的信息层级。
4. 关键 CTA 链接到仓库内维护的部署说明，避免在页面复制可能过期的基础设施命令。

## 当前实现

- 首屏、产品截图、L1/L2/L3 能力条和自托管 CTA。
- 三项价值说明、个人 / Agent 记忆切换、MCP 客户端入口和页尾导航。
- 响应式导航与桌面、平板、手机布局。
- 键盘跳转链接、可访问的移动导航状态与 `aria-pressed` 记忆切换。

## 验证方式

- 使用 Edge 检查 1440px 和 390px 宽度，确认没有横向溢出、文本重叠或无法触达的操作。
- 点击个人 / Agent 记忆切换，确认三层流程与边界文案一起更新。
- 运行根目录 `pnpm gate` 与 `git diff --check`。
