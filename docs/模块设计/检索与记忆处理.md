# 检索与记忆处理

> 模块定位：负责混合召回、排序、证据组织和来源感知问答。
>
> 对应代码：`src/features/search/*`、`src/features/chat/*`、`src/platform/vector/*`、`src/platform/ai/workers-ai/*`
>
> 所属 M 里程碑：[`M1 检索与问答`](../roadmap.md#m1-检索与问答)
>
> 当前状态：已完成
>
> 最近更新时间：2026-08-02

## 职责与边界

- 搜索模块并行获取 Vectorize、D1 FTS5/BM25 与 L2 图谱候选。
- 排序模块完成 RRF 融合、Workers AI 重排、MMR 去重和资产级证据分组。
- 问答模块使用检索证据生成回答与来源信息，并处理模型失败时的降级。
- 图谱数据的写入和维护归知识图谱模块；本模块只消费图召回结果。

## 结构与数据流

```text
query -> dense + lexical + graph -> RRF -> reranker -> MMR
      -> grouped evidence -> search response / grounded answer
```

检索条件会尽早下推到 D1 和 Vectorize。最终结果按资产组织，调用方仍可继续
查看具体 chunk、摘要和来源。

记录归属过滤统一使用 `recordKinds`、`scopeIds`、`contextKeys`。每个数组内部按 OR，
三个维度之间按 AND；省略维度表示不限。旧单值参数在兼容期继续可用。

## 关键决策

1. 召回融合使用排名，避免直接比较不同通道的原始分数。
2. reranker 请求遵循 Cloudflare 的 `query + contexts + top_k` 结构。
3. reranker 或问答模型失败时保留已有证据，搜索请求仍能返回可用结果。
4. 离线 eval 用确定性替身检查管线接线，真实模型质量另做 Cloudflare 冒烟。
5. Ask 直接消费 Search 的混合检索与分组结果，只在回答阶段执行来源去噪、证据门槛和
   答案生成，避免两套召回逻辑产生 fallback 行为差异。
6. `summary_only` 只把摘要交给问答模型；中文相关性按连续双字衡量，避免无空格文本被
   误判为没有相关词。

## 当前实现

- 结构与 token 感知切块，支持 query/document embedding 用途区分。
- D1 FTS5/BM25、Vectorize 原生过滤、图增强召回和 RRF 融合。
- `bge-reranker-base` 重排、MMR 多样性控制和 grouped evidence。
- 25 条金标准查询分阶段度量 lexical、dense、fused、reranked。
- Search REST/Web、`search_assets*` MCP 和 Ask 共用同一检索主干。
- `ask_library_for_context` 会继承 Search 的 profile、`allowFallback`、混合排序和
  `resultScope`；非首选领域的相关 `summary_only` 摘要可参与回答，原始正文仍不可见。
- 三维数组过滤贯穿 D1 lexical/summary、Vectorize dense、L2 graph 和 Ask；搜索与
  召回返回实际应用的 `appliedRecordFilters`。
- 默认列表、FTS、摘要、dense 的 D1 补齐和图证据 hydration 排除已被取代的 memory
  版本，避免版本历史重新进入当前召回；按 ID 查看历史不受影响。
- summary-only 评分与 Ask 的中文覆盖判断共用 CJK-aware 双字 tokenizer，连续中文查询
  不再因缺少空格而被低估。
- Web 页面显式传 personal scope；通用 API/MCP 省略维度时保持不限。
- Recall 支持日期窗口以及 relevance、recency 两种排序方式。

```bash
pnpm build
```

重点测试位于 `tests/unit/features/search/`、`tests/unit/features/chat/`、
`tests/unit/platform/vector/` 和 `tests/eval/`。

`tests/unit/features/chat/server/service.test.ts` 覆盖“非首选领域 + `summary_only` +
`allowFallback=true` + 首选领域干扰 chunk”的组合，验证返回
`fallback_expanded`、摘要来源和正文隔离。
