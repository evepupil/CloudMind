# 高级记忆模态

> 模块定位：让记忆可以按时间、关系、评价维度和跨条目计算被找回。
>
> 对应代码：`src/features/search/server/{recall,service}.ts`、`src/features/memory/server/{graph-recall,salience}.ts`、`src/features/mcp/server/service.ts`、`tests/eval/*`
>
> 所属 M 里程碑：[`M5 高级记忆模态`](../roadmap.md#m5-高级记忆模态)
>
> 当前状态：进行中
>
> 最近更新时间：2026-07-22

## 职责与边界

- 时间模态处理日期范围、最近优先和未来的事件锚定。
- 联想模态通过图关系扩展语义检索难以直接命中的内容。
- 评价模态计划按重要性、情感效价、成就感等通用维度排序。
- 聚合模态计划对一批记忆做计数、趋势和摘要。

## 结构与数据流

```text
query + time/order/filter -> scoped recall -> salience + hybrid ranking
relation query           -> graph expansion -> search fusion
future rating/aggregate  -> candidate set -> dimension scoring / reduction
```

## 关键决策

1. 日期输入统一转换为带时区的绝对范围，再进入 repository 过滤。
2. recency 和 relevance 是明确的排序模式，调用方可以选择。
3. 评价维度保持通用，不为单一日记或习惯场景写死模型。
4. 新模态先加入可复现 eval 样本，再调整写入与排序。

## 当前实现

- `createdAtFrom`、`createdAtTo`、`timezoneOffsetMinutes` 日期窗口。
- `relevance` 与 `recency` recall 排序。
- recency、importance、access count 组成的显著性加权。
- scope 内实体关系扩展与图召回融合。

## 验证方式

日期边界和排序由 recall 单测覆盖，显著性由 salience 单测覆盖，关系通道由
graph recall 与 search graph-channel 单测覆盖。新增模态必须同时扩展 eval 金标准。

## 待扩展项

- 相对事件锚定和基于 `occurred_at` 的情节召回。
- 评价维度写入、超级值排序与陌生维度的批量评分兜底。
- 跨记忆计数、趋势、阶段总结和可引用的聚合结果。
